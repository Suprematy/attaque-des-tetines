# L'Attaque des Tétines

Jeu d'action en 3D dans le navigateur : équipement de manœuvre tridimensionnel, grappins, gaz et deux lames. Le but est de trancher la nuque des géants, vague après vague.

## Jouer

**👉 [Jouer dans le navigateur](https://suprematy.github.io/attaque-des-tetines/)**

Il n'y a rien à installer ni à télécharger. Le jeu s'ouvre dans Chrome, Edge ou Firefox, de préférence sur un ordinateur avec souris et clavier. Au premier chargement, il récupère environ 160 Mo de modèles et de textures ; ensuite, le navigateur les garde en cache.

## Commandes principales

| Touche | Action |
|---|---|
| Souris | Viser |
| Clic droit (maintenir) | Double grappin |
| A / E (Q / E en QWERTY) | Grappin gauche / droit |
| Clic gauche | Trancher (maintenu puis relâché en l'air : coupe chargée) |
| Espace | Saut, boost de gaz |
| Shift | Dash |
| ZQSD / WASD | Se déplacer |
| C / X / F | Salto / vrille / tourbillon |
| V ou 1 à 4 | Changer de caméra |
| Tab | Menu (améliorations, graphismes, commandes) |
| Échap | Pause |

## Si le jeu rame

Ouvre **Tab → Graphismes** :

- passe les **textures** en « Basses » ;
- passe les **ombres lointaines** en « Désactivées » ;
- règle les **shaders** sur « Légers » ;
- laisse la **limite d'images par seconde** à 60.

Sur les puces graphiques intégrées, le jeu choisit déjà des réglages allégés au premier lancement.

## Modes

Mode RPG, mode classique, The Rumbling, vague de boss, assaut final, PvP contre des IA et multijoueur en ligne (2 à 4 joueurs, coop ou PvP).
